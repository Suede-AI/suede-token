## What is $SUEDE?

$SUEDE is the utility token for Suede Labs AI — a programmable IP and creator ownership infrastructure built for the AI-native media era.

Suede is built around ownership first: provenance, rights registration, licensing, monetization, and agent-accessible commerce for creator-owned assets. Music is the initial high-signal media category and the primary production use case. The scope extends to all creative IP and AI-generated assets.

Core capabilities the token is connected to:

- On-chain IP registration and provenance (Base + Avalanche + Solana)
- Creator licensing and royalty infrastructure
- x402 micropayment rails for agent commerce
- ACP-ready autonomous agent endpoints
- Token-holder access and utility across Suede products

> "Build what doesn't exist yet. Register that you built it. That sequence is the whole game."

> "Your most valuable asset isn't the song. It's the provenance of the song."
